# 🌦️ Weather App

A modern and responsive Weather Application built using **HTML, CSS, and JavaScript** that provides real-time weather updates using API integration.

---

## 🚀 Features

- 🌍 Get weather using current location (Geolocation API)
- 🔍 Search weather by city name
- 🌡️ Shows temperature, humidity, wind speed
- ⚡ Fast and responsive UI
- 💾 Uses session storage
- 🔄 Tab switching (Your Weather / Search Weather)

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- OpenWeatherMap API

## 🔑 Setup Instructions

1. Clone the repository:

```bash
git clone https://github.com/abhi9-git-hub/weather-app.git
```

2. Open project folder:

```bash
cd weather-app
```

3. Open index.html in browser
